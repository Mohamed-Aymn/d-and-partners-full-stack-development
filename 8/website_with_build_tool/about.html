About Shelf

The same Shelf site, bundled with Vite — HTML, CSS, JavaScript, and npm packages.

Each screen is its own HTML document. Shared styles live in styles/common/, page styles in styles/pages/, and scripts in js/. Books are stored in sessionStorage.

  • Vite for dev server and production builds
  • BEM class names with @scoped page CSS
  • ES modules + import from zod and state-management.js
  • Session storage with mock seed books when empty
